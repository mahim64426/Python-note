০৩ ভ্যারিয়েবল ও ডেটা টাইপ

পাইথনে ভ্যারিয়েবল ঘোষণার জন্য কোনো কীওয়ার্ড (var/let) লাগে না — সরাসরি অ্যাসাইন করলেই ভ্যারিয়েবল তৈরি হয়।

age = 18        # age এখন int টাইপের
name = "Mahim"   # name এখন str টাইপের
print(name)

x = y = z = 10     # মাল্টিপল অ্যাসাইনমেন্ট — সবাইকে একই ভ্যালু
a, b, c = 1, 2, 3  # একসাথে একাধিক ভ্যারিয়েবল অ্যাসাইন
a, b = b, a        # দুই ভ্যারিয়েবলের ভ্যালু অদল-বদল (swap), temp দরকার নেই

ডেটা টাইপ চেক করা

x = 10
print(type(x))              # <class 'int'>
print(isinstance(x, int))   # True

ভ্যারিয়েবল নেমিং নিয়ম

  • অক্ষর, সংখ্যা, আন্ডারস্কোর (_) দিয়ে নাম হতে পারে, কিন্তু সংখ্যা দিয়ে শুরু করা যাবে না।
  • কেস-সেনসিটিভ: age এবং Age আলাদা ভ্যারিয়েবল।
  • পাইথন কীওয়ার্ড (if, for, class ইত্যাদি) ভ্যারিয়েবলের নাম হিসেবে ব্যবহার করা যাবে না।
  • কনভেনশন: ভ্যারিয়েবল/ফাংশনের জন্য snake_case, ক্লাসের জন্য PascalCase, কনস্ট্যান্টের জন্য UPPER_CASE।

Global ও Local ভ্যারিয়েবল

x = "global"
def my_func():
    x = "local"   # ফাংশনের ভেতরে এটা আলাদা লোকাল ভ্যারিয়েবল
    print(x)      # local

my_func()
print(x)   # global
