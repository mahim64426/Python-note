পাইথন সম্পূর্ণ চিট শিট

Python 3.x — একদম শুরু থেকে অ্যাডভান্সড লেভল পর্যন্ত সম্পূর্ণ, বিস্তারিত ও হালনাগাদ বাংলা রেফারেন্স গাইড।
কোড ইংরেজিতে (স্ট্যান্ডার্ড), ব্যাখ্যা সম্পূর্ণ বাংলায়।

০১ পাইথন পরিচিতি ও ইতিহাস

পাইথন একটি হাই-লেভেল, ইন্টারপ্রেটেড, জেনারেল-পারপাস প্রোগ্রামিং ভাষা। এটি সহজ সিনট্যাক্স, রিডেবিলিটি এবং বিশাল লাইব্রেরি ইকোসিস্টেমের জন্য পরিচিত। ওয়েব ডেভেলপমেন্ট, ডেটা সায়েন্স, মেশিন লার্নিং, অটোমেশন, স্ক্রিপ্টিং — সব জায়গায় পাইথন ব্যবহৃত হয়।

Hello World

print("Hello, World!")

পাইথন রান করা

python script.py    # স্ক্রিপ্ট ফাইল রান করা
python              # ইন্টারঅ্যাক্টিভ শেল (REPL) চালু করা
python -c "print(1+1)"   # সরাসরি কমান্ড রান করা

পাইথনের বৈশিষ্ট্য

  • ডায়নামিকভাবে টাইপড: ভ্যারিয়েবলের টাইপ আগে থেকে ঘোষণা করতে হয় না।
  • ইন্টারপ্রেটেড: কোড লাইন বাই লাইন এক্সিকিউট হয়, কম্পাইল করার প্রয়োজন নেই।
  • হোয়াইটস্পেস-সেনসিটিভ: কোড ব্লক নির্ধারণে ইন্ডেন্টেশন ব্যবহৃত হয়, {} লাগে না।
  • মাল্টি-প্যারাডাইম: প্রসিডিউরাল, অবজেক্ট-ওরিয়েন্টেড এবং ফাংশনাল — তিন ধরনের স্টাইলেই কোড লেখা যায়।

'''

ইন্ডেন্টেশন

পাইথনে কোড ব্লক (if, for, function ইত্যাদির ভেতরের কোড) নির্ধারণ হয় ইন্ডেন্টেশন (স্পেস/ট্যাব) দিয়ে — কার্লি ব্রেস {} লাগে না। সাধারণত ৪ স্পেস ব্যবহার করা হয়।

if True:
    print("এই লাইন if ব্লকের ভেতরে")
    print("এটাও")
print("এটা if ব্লকের বাইরে")

print() ফাংশন

print("Hello", "World")                    # আউটপুট: Hello World
print("Hello", "World", sep="-")            # আউটপুট: Hello-World
print("Hello", end=" ")                     # নতুন লাইনে যাবে না, স্পেস দিয়ে শেষ হবে
print("A", "B", "C", sep=", ", end="!\n")   # আউটপুট: A, B, C!

ভ্যারিয়েবল নেমিং নিয়ম

  • অক্ষর, সংখ্যা, আন্ডারস্কোর (_) দিয়ে নাম হতে পারে, কিন্তু সংখ্যা দিয়ে শুরু করা যাবে না।
  • কেস-সেনসিটিভ: age এবং Age আলাদা ভ্যারিয়েবল।
  • পাইথন কীওয়ার্ড (if, for, class ইত্যাদি) ভ্যারিয়েবলের নাম হিসেবে ব্যবহার করা যাবে না।
  • কনভেনশন: ভ্যারিয়েবল/ফাংশনের জন্য snake_case, ক্লাসের জন্য PascalCase, কনস্ট্যান্টের জন্য UPPER_CASE।

স্ট্রিং-এর গুরুত্বপূর্ণ মেথড

মেথডকাজউদাহরণ
.upper()সব বড় হাতের অক্ষরে"abc".upper() → "ABC"
.lower()সব ছোট হাতের অক্ষরে"ABC".lower() → "abc"
.title()প্রতি শব্দের প্রথম অক্ষর বড়"hi there" → "Hi There"
.strip()দুই পাশের স্পেস মুছে" hi ".strip() → "hi"
.replace(a,b)a কে b দিয়ে রিপ্লেস"aa".replace("a","b") → "bb"
.split(sep)সেপারেটর দিয়ে ভাগ করে লিস্ট বানায়"a,b".split(",") → ["a","b"]
.join(iter)লিস্টকে স্ট্রিং-এ জোড়ে",".join(["a","b"]) → "a,b"
.find(sub)সাবস্ট্রিং-এর ইনডেক্স (না পেলে -1)"hello".find("l") → 2
.count(sub)কতবার আছে গোনে"aaa".count("a") → 3
.startswith(x)শুরু হয় কিনাTrue/False
.isdigit()শুধু ডিজিট কিনাTrue/False
.zfill(n)সামনে ০ দিয়ে ভরে"7".zfill(3) → "007"
স্ট্রিং immutable — একবার তৈরি হলে এর ভেতরের ভ্যালু বদলানো যায় না। নতুন স্ট্রিং বানাতে হয়: s = "H" + s[1:]

@property, @staticmethod, @classmethod

class Circle:
    pi = 3.1416
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("রেডিয়াস নেগেটিভ হতে পারবে না")
        self._radius = value

    @property
    def area(self):
        return self.pi * self._radius ** 2

    @staticmethod
    def is_valid_radius(value):
        return value > 0

    @classmethod
    def unit_circle(cls):
        return cls(1)

c = Circle(5)
print(c.radius)   # 5 (() ছাড়া কল হচ্ছে, কারণ @property)

class Counter:
    def __init__(self, limit):
        self.limit = limit
        self.current = 0
    def __iter__(self):
        return self
    def __next__(self):
        if self.current < self.limit:
            self.current += 1
            return self.current
        raise StopIteration

def repeat(times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

def greet():
    print("Hi!")
